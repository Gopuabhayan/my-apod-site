# my-apod-site

a minimalistic clean and modern looking custom apod-site that gets its background from nasa's astronomy picture of the day api.

![newtab](assetes/page.png)


## description
get rid of your boring, lifeless and default apod-site. this is a functional apod-site that provides modern aesthetics and limited customizability. also features a news section . the background images are updated from nasa's apod (astrology picture of the day).


## features
- responsive
- apod background images
- news section
